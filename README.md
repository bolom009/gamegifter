# 🎁 GameGifter — колесо для розыгрыша игр на Twitch

Статичная страница (без сервера и сборки): колесо фортуны, регистрация зрителей прямо из чата Twitch, выбор игр, режим «на выбывание», проверка присутствия победителя, конфетти и звуки.

## Как опубликовать на GitHub Pages

1. Создайте на GitHub публичный репозиторий, например `gamegifter`.
2. Загрузите в него файлы `index.html`, `style.css`, `app.js`, `games.json`, `.nojekyll`
   (через сайт: **Add file → Upload files**, или через git — см. ниже).
3. В репозитории откройте **Settings → Pages**, в разделе *Build and deployment* выберите
   **Source: Deploy from a branch**, ветка **main**, папка **/ (root)** → **Save**.
4. Через 1–2 минуты страница будет доступна по адресу
   `https://<ваш-логин>.github.io/gamegifter/`.

Ссылку можно сразу отдать стримеру с его каналом:
`https://<ваш-логин>.github.io/gamegifter/?channel=ник_стримера` — чат подключится автоматически.

Через git:

```bash
git remote add origin https://github.com/<ваш-логин>/gamegifter.git
git push -u origin main
```

## Как заполнить список игр

Откройте в репозитории файл `games.json` (карандаш ✏️ «Edit this file») и перечислите игры:

```json
[
  { "title": "Hades II", "steamAppId": "1145350" },
  { "title": "Hollow Knight", "steamAppId": "367520", "count": 2 },
  { "title": "Какая-то игра не из Steam", "image": "https://example.com/cover.jpg", "platform": "GOG" }
]
```

| Поле | Обязательно | Что это |
|---|---|---|
| `title` | да | Название игры |
| `steamAppId` | нет | ID игры в Steam — число из ссылки `store.steampowered.com/app/`**`1145350`**`/…`. По нему подтянется обложка |
| `image` | нет | Своя картинка (URL). Перекрывает обложку Steam |
| `platform` | нет | Подпись: Steam, GOG, Epic… |
| `count` | нет | Сколько ключей этой игры разыгрывается (по умолчанию 1) |

Порядок в файле = номера игр для команды в чате (первая игра — `1`, вторая — `2`…).
Не меняйте порядок и названия во время уже идущей регистрации.

> ⚠️ **Не кладите сами ключи в репозиторий** — GitHub Pages публичный, файл может открыть кто угодно.
> Ключ победителю отправляйте лично (в ЛС Twitch / Discord).

Стример также может поменять список у себя кнопкой ✏️ над играми — это сохраняется только в его браузере.
Там же есть «Экспорт games.json», чтобы скачать готовый файл и загрузить его в репозиторий.

## Как регистрируются зрители

Ничего ставить и авторизовывать не нужно: страница анонимно читает чат канала (как любой зритель без логина).
Зрители пишут в чат:

| Команда | Что делает |
|---|---|
| `!join` | Участвовать во всех играх |
| `!join 1 3` | Участвовать только в играх №1 и №3 (можно через пробел или запятую) |
| `!join` ещё раз | Поменять выбор игр |
| `!leave` | Выйти из розыгрыша |

Команды можно переименовать в ⚙ настройках. Стример может добавить человека вручную или удалить (✕ у ника).

## Что может стример

- **Подключить канал** — ник сверху → «Подключить» (или ссылка с `?channel=`).
- **📋 Текст для чата** — копирует готовое объявление со списком игр и номерами.
- **Открыть/закрыть регистрацию** одной кнопкой.
- **Выбрать игру** слева — на колесе останутся только те, кто её выбрал.
- **Режим**: 🎯 «Один победитель» или 💥 «На выбывание» (каждый спин убирает одного, последний — победитель; авто‑продолжение можно поставить на паузу).
- **Длительность раскрутки** (3–120 с) и отдельная длительность раундов выбывания (финал из двух человек идёт с основной длительностью).
- **Характер остановки**: плавное, драматичное (долго ползёт) или «интрига» (проскакивает и откатывается).
- **Только сабы** и **удача сабов** (×1…×5 — сектор саба больше).
- **Победитель не участвует в следующих играх**.
- **Проверка присутствия**: победитель должен написать в чат за N секунд — страница сама это увидит; иначе «Перекрутить без него».
- **🏆 Итоги** — копирует список победителей для чата.
- **🧪 Тест** — добавляет фейковых участников, чтобы попробовать колесо.
- Пробел — крутить. Участники и итоги переживают перезагрузку страницы (хранятся в браузере).

Для трансляции: в OBS добавьте «Захват окна» браузера с этой страницей.

## Локальный запуск

```bash
python -m http.server 8765
```

и откройте <http://localhost:8765>. (Открыть `index.html` двойным кликом не выйдет — браузер не даст загрузить `games.json` с диска.)
